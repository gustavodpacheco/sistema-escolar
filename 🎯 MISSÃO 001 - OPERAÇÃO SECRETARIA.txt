🎯 MISSÃO 001 - OPERAÇÃO SECRETARIA DIGITAL
DS QUEST MASTER
Sprint 01 - Primeira Entrega da Software House
________________________________________
📖 CONTEXTO
A direção da escola decidiu acabar com o cadastro em papel.
Todos os dados dos alunos estão espalhados em fichas, cadernos e planilhas.
A secretaria precisa urgentemente de um sistema digital para cadastrar alunos.
Sua Software House foi contratada para desenvolver a primeira versão.
________________________________________
🎯 MISSÃO
Criar a primeira versão do sistema de cadastro de alunos.
Cada Squad deverá entregar:
✅ Tela de cadastro
✅ Estrutura de armazenamento dos dados
✅ Modelagem inicial do banco
✅ Evidências de funcionamento
________________________________________
👥 DIVISÃO DAS RESPONSABILIDADES
🎨 Desenvolvedor Front-End
Criar a tela de cadastro contendo:
•	Nome
•	E-mail
•	Data de nascimento
•	Série
•	Botão Salvar
Pode utilizar apenas:
•	HTML
•	CSS
________________________________________
⚙️ Desenvolvedor Back-End
Criar um programa JavaScript capaz de armazenar 5 alunos.
Deverá exibir os alunos cadastrados no console.
Pode utilizar:
•	Variáveis
•	Arrays
•	Objetos
________________________________________
🗄️ Desenvolvedor Banco de Dados
Criar a primeira modelagem.
Tabela:
ALUNOS
Campos:
id
nome
email
data_nascimento
serie
Pode ser entregue em papel ou draw.io.
________________________________________
🧪 Desenvolvedor QA
Validar:
✅ Formulário funcionando
✅ Campos completos
✅ Dados armazenados
✅ Apresentação organizada
Criar checklist de testes.
________________________________________
